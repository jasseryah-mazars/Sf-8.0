# Audit & Enhancement Policy

A **standing rule** for the whole repository, all phases, all files. This is a
continuous-improvement system, not a one-time generation.

## 1. Official sources requirement (mandatory)

Every syllabus micro-chapter **must** end with a `## Official References` section:

- **Symfony concepts** → official Symfony docs (`https://symfony.com/doc/current/…`),
  plus component/config/best-practice pages and Symfony **source** links when
  internals are discussed.
- **PHP concepts** → the PHP manual (`https://www.php.net/manual/en/…`) and the
  relevant `https://www.php.net/releases/…` page for version features.
- **RFCs / design docs** when relevant.

A section/chapter is **invalid without references**. Enforced by
[DefinitionOfDone](DefinitionOfDone.md), [ReviewChecklist](ReviewChecklist.md),
and `tools/audit.py`.

## 2. Continuous completeness audit (mandatory)

After generating or modifying **any** content, run `python tools/audit.py`, which:

1. **Maps** every official syllabus item → chapter(s) and marks
   ✔ fully covered / ⚠ partially covered / ❌ missing (against
   [TraceabilityMatrix](TraceabilityMatrix.md) and the file tree).
2. **Detects gaps**: missing topics, weak coverage, missing deep dives, missing
   references, missing traps, missing exercises, missing exam-style questions.
3. Regenerates **[CoverageReport.md](CoverageReport.md)**.

## 3. Auto-remediation — INCREASE COVERAGE ONLY

For every gap: **add** sections, **extend** chapters, **enrich** explanations, add
deep dives / traps / exercises / mock questions.

## 4. No content removal policy

Never delete sections, never "simplify" by removing depth, never replace a deep
explanation with a shorter one. Allowed operations only:

✔ Add · ✔ Extend · ✔ Improve · ✔ Fix inaccuracies · ✔ Add missing syllabus coverage

(Renaming a heading or fixing a factual error is *improvement*, not removal.)

## 5. Required output each iteration

- **Coverage Report** — total syllabus items, % covered / partial / missing
  (see [CoverageReport.md](CoverageReport.md), regenerated by the audit script).
- **Improvement Log** — what was added / expanded / fixed (kept in the PR/commit
  message and appended to [CoverageReport.md](CoverageReport.md)).

## 6. Goal

100% syllabus coverage + expert deep dives + full official-reference traceability
+ zero missing items — maintained continuously across future Symfony releases
(see [FutureMaintenance](FutureMaintenance.md)).
