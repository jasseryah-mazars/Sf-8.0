# Tags

Browse content by tag. Useful for cross-topic study (e.g. everything tagged
*Security* or *Testing*).

## 🧠 Pour les nuls

**C'est quoi cette page ?** Un index qui regroupe tous les chapitres partageant une même étiquette (par exemple "Sécurité"), même s'ils appartiennent à des domaines différents.

**Pourquoi ça existe ?** Certains sujets transversaux (comme CSRF, qui touche à la fois Forms et Security) sont difficiles à retrouver en parcourant un seul domaine à la fois — les tags permettent de les regrouper artificiellement.

**🏠 Analogie de la vraie vie :** Les rayons "coup de cœur" d'une librairie, qui regroupent des livres de genres très différents (roman, essai, BD) autour d'un même thème transversal, plutôt que de suivre le classement habituel par genre.

**Symfony dans la vraie vie :** Chercher le tag "CSRF" ici peut faire remonter à la fois un chapitre de Forms et un chapitre de Security — les deux traitent du même mécanisme sous un angle différent.

**⚠️ Erreur fréquente :** utiliser cette page comme point d'entrée principal de révision — elle est faite pour des recherches ponctuelles transversales, pas pour suivre un parcours structuré (voir plutôt le [Roadmap](roadmap.md)).

**🧠 Comment le mémoriser :** "Les tags relient des sujets par thème, pas par domaine — utile pour chercher, pas pour apprendre dans l'ordre."
