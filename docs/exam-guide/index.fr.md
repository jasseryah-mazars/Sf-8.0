# Guide de l'examen

Tout ce qu'il faut comprendre sur la **Certification Symfony 8** avant de commencer
à étudier : ce qu'est l'examen, comment il est noté, en quoi les deux niveaux
diffèrent, et comment l'étudier et le passer efficacement.

!!! abstract "The exam at a glance"
    - **75 questions** en **90 minutes** (~72 secondes chacune).
    - Questions à **choix unique, choix multiple et vrai/faux**.
    - Un seul examen, deux résultats possibles : **Advanced** ou **Expert**, décidés
      par votre score.
    - Socle **PHP 8.4+** (une exigence de Symfony 8).
    - Couvre les **14 domaines officiels** ; Messenger est davantage pondéré,
      HTTP Caching moins pondéré par rapport à Symfony 7.

## Before you dive in

1. Survolez [Exam Format & Scoring](format.md) pour que la structure soit claire.
2. Décidez de votre niveau cible dans [Advanced vs Expert](levels.md).
3. Ouvrez la [Roadmap](../roadmap.md) et commencez à étudier dans l'ordre recommandé.
4. Gardez le [Revision Hub](../revision/index.md) pour la dernière ligne droite.

!!! info "Official source"
    Vérifiez toujours les modalités en vigueur sur la page officielle :
    [certification.symfony.com](https://certification.symfony.com/). Ce guide
    explique comment se préparer ; c'est l'organisme certificateur qui définit
    l'examen.
